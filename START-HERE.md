# Установка памяти агентом на новом компьютере

Этот файл — входная точка для агента получателя. Здесь нет памяти автора,
ключей или его машинных настроек. Используй только учётные записи владельца
нового компьютера. Статус разрешения на распространение — в LICENSING.md;
не считай открытый GitHub-репозиторий автоматически лицензированным.

## Сообщение, которое владелец передаёт агенту

> Установи мне Wiki Agents из этого репозитория. Начни с START-HERE.md, затем
> прочитай INSTALL.md. Определи мою ОС и доступные программы. Уточни только
> движок, резервный движок и один проект для пилота. Объясни, какие данные
> отправляются выбранному провайдеру. Сохрани прежние настройки, установи
> память и проверь запись, компиляцию, восстановление в новой сессии и отмену
> тестового решения. Не изменяй остальные проекты, не публикуй мою память и
> не объявляй успех, если автоматическая цепочка не работает. В конце дай
> результат проверки и точную команду отката.

## Обязательный порядок для агента

1. Прочитай AGENTS.md и INSTALL.md. Проверена macOS + Python 3.12 + uv + Luna;
   Linux/Windows и живые Haiku/Grok не подтверждены этой поставкой. На другой
   платформе сначала проверь пилот; не обещай совместимость заранее.
2. Проверь наличие Git, uv и CLI выбранного движка. Отсутствующие программы
   устанавливай только согласованным с владельцем способом. Авторизацию
   выполняет владелец: не проси вставлять секреты в чат или файлы проекта.
3. Подтверди три выбора: primary, fallback (включая none), точный путь одного
   проекта. Дополнительно выясни, нужен ли Claude Code: без него используй
   `--no-claude`, не меняя глобальные Claude hooks. Не задавай широкий `--root`
   для первого пилота.
4. Объясни передачу данных: выбранный CLI получает выдержки разговоров и wiki
   для обработки, это не полностью локальная модель. Не импортируй чужую память,
   production DB или секреты. При неясном согласии останови внешнюю обработку.
5. Размести исходники в постоянном отдельном каталоге. Не накладывай их поверх
   грязной установки. Зафиксируй использованный commit/tag и версию pyproject.
6. Выполни `uv sync --frozen`, автоматические тесты и `install.py --dry-run`.
   Если память уже существует, сначала сохрани её управляющие файлы и статьи:
   `manage.py upgrade --project ...` создаёт точку отката до изменений. Для
   первоначальной установки также сохрани существующие hooks и инструкции.
7. Запусти установщик с подтверждёнными параметрами. Сохрани полный итог:
   engine check, созданные файлы и ограничения. В Desktop попроси владельца
   проверить и доверить конкретный hook; не отключай проверку доверия глобально.
8. Проверь цепочку в отдельном разрешённом пилотном проекте: запиши уникальное
   синтетическое решение в сессии; дождись записи в daily; скомпилируй только
   этот источник; найди решение в новой сессии; отмени его и проверь, что оно
   больше не выдаётся действующим. Проверь повтор без дубликатов и lint.
   Тестовый проект сохраняй отдельно от реальной памяти. Не очищай чужие данные.
9. Выдай `OK` только при всей пройденной цепочке. Иначе `PARTIAL` с одним
   конкретным требуемым действием. Не подключай другие проекты автоматически.

## Правильный контекст проекта

`manage.py` принимает `--project`. Для `compile.py`, `query.py`, `lint.py` и
`import_source.py` проект указывается через `CMC_PROJECT_DIR`: запуск из каталога
механизма без этого параметра может проверить не тот каталог.

Пример для macOS/Linux после замены двух путей и подтверждения Luna:

```bash
uv run --directory /path/to/wiki-agents python scripts/install.py \
  --caller codex --engine luna --fallback none --no-claude \
  --project /path/to/project --dry-run

uv run --directory /path/to/wiki-agents python scripts/install.py \
  --caller codex --engine luna --fallback none --no-claude \
  --project /path/to/project

CMC_PROJECT_DIR=/path/to/project uv run --directory /path/to/wiki-agents \
  python scripts/lint.py --structural-only

CMC_PROJECT_DIR=/path/to/project uv run --directory /path/to/wiki-agents \
  python scripts/query.py 'Какое решение сейчас действует?'

uv run --directory /path/to/wiki-agents python scripts/manage.py \
  status --project /path/to/project
```

Пути с пробелами заключай в кавычки. Команды не предназначены для буквального
копирования без подстановки реальных путей. Для Windows используй синтаксис
своей оболочки и отдельно проверь поддержку hooks.

## Итог установки для владельца

Сообщи: версию/commit, каталог установки, проект, движок/fallback, результат
каждого шага цепочки, изменённые настройки, точку отката и команды status,
query, lint, rollback/uninstall с его реальными путями. Не показывай секреты.
Не обещай экономию токенов или точность, не измеренные на его памяти.
